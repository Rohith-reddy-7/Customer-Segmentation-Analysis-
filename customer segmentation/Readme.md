# Customer Segmentation Analysis using RFM and K-Means

## Project Overview
This project performs customer segmentation using RFM Analysis and K-Means Clustering to identify valuable customer groups for targeted marketing strategies.

## Features
- Data Cleaning
- RFM Analysis
- Customer Segmentation
- Data Visualization
- Business Recommendations
- Interactive Power BI Dashboard
